# Aconchego

Site acadêmico de uma ONG fictícia chamada Aconchego. O projeto foi feito com HTML, CSS e JavaScript, sem frameworks ou servidor.

## Como abrir

Não é preciso instalar nada. Basta abrir o arquivo `index.html` no navegador.

As outras páginas do projeto são:

- `projetos.html`
- `cadastro.html`

## O que o site tem

- apresentação da ONG;
- equipe, galeria e notícias;
- informações sobre projetos sociais;
- tabela de indicadores e transparência;
- formulário de cadastro;
- newsletter demonstrativa;
- máscaras para CPF, telefone e CEP;
- menu responsivo;
- simulação de doação única ou mensal;
- mensagem de confirmação para os formulários.

Os formulários não enviam nem guardam dados. A doação também não realiza pagamento.

## Pastas principais

- `css/estilo.css`: estilos compartilhados das páginas;
- `js/script.js`: interações do menu e dos formulários;
- `img/`: logotipo e imagens usadas no site;
- `media/`: reservada para um vídeo institucional.

## Observações

A pasta `media` não recebeu um vídeo junto com os arquivos do projeto. Por isso, a página de projetos mostra um aviso no lugar do vídeo. Também não foi mantido o vídeo externo que estava relacionado a outro conteúdo.

As imagens são ilustrativas e foram obtidas do Pexels. O logotipo usado no cabeçalho foi fornecido para este projeto.

Este é um projeto estático para fins acadêmicos. Não possui login, banco de dados, área administrativa ou sistema de pagamento.

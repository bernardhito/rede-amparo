# Aconchego

Site acadêmico de uma ONG fictícia, feito com HTML, CSS e JavaScript.

## Como abrir

Abra o arquivo `index.html` no navegador. Não é necessário instalar nada.

O projeto possui três páginas:

- `index.html`
- `projetos.html`
- `cadastro.html`

## Funcionalidades

- menu responsivo;
- navegação entre as páginas;
- formulário de cadastro;
- máscaras de CPF, telefone e CEP;
- newsletter demonstrativa;
- simulação de doações;
- informações sobre os projetos da ONG.

Os formulários não enviam nem salvam dados. A doação não realiza pagamentos.

As imagens ficam na pasta `img`. A pasta `media` está reservada para um vídeo institucional que ainda não foi fornecido.
